YouTube Uploader

A private Mac setup for the owner’s own YouTube channels, operated by Andesprit.

Current setup

Channel authorization and secure token storage are configured for Dollar Mechanics. Video uploading and automatic scheduling are not yet implemented.

Channel access

The setup uses YouTube API Services and Google OAuth to connect the channel selected by its owner. It requests only the YouTube upload permission, youtube.upload.

Google handles sign-in and consent. The connection helper obtains, refreshes and stores the selected channel’s authorization. This information page does not offer public signup or a hosted uploading service.

Stored on the Mac

The OAuth client configuration is kept in a private local folder outside code repositories. Channel credentials are stored in macOS Keychain. Local connection receipts record the selected channel and authorization status without storing tokens in those receipts.

The owner stays in control

Any future upload workflow must be authorized for the selected channel, video, metadata and visibility settings. Such an upload would send that video and metadata to YouTube.

The current setup has not uploaded a video. Public API publishing and unattended scheduling have not been verified. Connecting a channel does not authorize an upload.

Terms and privacy

This setup uses YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service.

Read the YouTube Uploader privacy disclosure before using the setup. It explains local storage, revocation and manual deletion.
